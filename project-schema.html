🏪 Схема проекта Cafe iOS App

Base URL: https://anton.panfilius.ru/api

🔗 API Endpoints

Метод Endpoint Описание Тело запроса Ответ
POST /auth/login Авторизация пользователя LoginDTO AuthResponseDTO
POST /auth/register Регистрация пользователя RegisterDTO AuthResponseDTO
GET /me Получить текущего пользователя - UserDTO
PUT /me/update Обновить профиль UpdateProfileDTO UserDTO
GET /products Получить все продукты - [Product]
GET /product/{id} Получить продукт по ID - Product
POST /products/search Поиск продуктов SearchDTO [Product]
GET /cart Получить корзину - CartDTO
POST /cart/items Добавить товар в корзину CartAddItemDTO CartDTO
PATCH /cart/items/{dessertId} Изменить количество товара CartSetQtyDTO CartDTO
DELETE /cart/items/{dessertId} Удалить товар из корзины - CartDTO
DELETE /cart Очистить корзину - CartDTO

⚙️ Сервисы

🔐 AuthService

  • login(login, password)
  • register(userData)
  • logout()
  • fetchMe() → UserDTO
  • updateMe(dto) → UserDTO

📦 ProductsService

  • fetchProducts() → [Product]
  • fetchProduct(id) → Product
  • searchProducts(dto) → [Product]

🛒 CartService

  • getCart() → CartDTO
  • addItem(dessertId, qty) → CartDTO
  • setQty(dessertId, qty) → CartDTO
  • removeItem(dessertId) → CartDTO
  • clearCart() → CartDTO

🌐 APIClient

  • request(path, method, body, authorized)
  • Обработка ошибок
  • Управление токенами
  • JSON encoding/decoding

🔗 Связи между моделями

UserDTO ↔ AuthService: Пользователь управляется через AuthService
Product ↔ ProductsService: Продукты загружаются через ProductsService
CartDTO ↔ CartService: Корзина управляется через CartService
CartDTO → CartItemDTO (1:N): Корзина содержит несколько товаров
CartItemDTO → CartDessertDTO (1:1): Каждый товар в корзине ссылается на десерт
APIClient ← Все сервисы: Все сервисы используют APIClient для HTTP запросов
AuthService → TokenStorage: Сервис авторизации управляет токенами

🏗️ Архитектура приложения

MVC + Services Layer

  • View Controllers: MainTabBarController, MenuViewController, CartViewController, etc.
  • Services Layer: AuthService, ProductsService, CartService, APIClient
  • Models: DTO структуры для API взаимодействия
  • Helpers: Расширения, утилиты
  • Resources: Ассеты, изображения, шрифты

Поток данных:

  1. ViewController вызывает метод сервиса
  2. Сервис формирует запрос через APIClient
  3. APIClient выполняет HTTP запрос с авторизацией
  4. Данные декодируются в DTO модели
  5. ViewController обновляет UI
